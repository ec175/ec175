## spectrometry.mp4

Physics you can watch. I write simulation and rendering engines in Python — the solver runs, and
the frames come out the other side. Nothing here is keyframed, traced or screenshotted.

### [spectrometry_public](https://github.com/ec175/spectrometry_public)

The engines behind the videos: lattice-Boltzmann fluid flow, electromagnetic field lines,
particle swarms, a simulated CRT, quantum orbitals and molecular spectra. Free to use, MIT.

Every curve is computed from a physical model rather than drawn — Lorentzian line-broadening,
Beer–Lambert, Boltzmann Stokes/anti-Stokes, Bragg's law, a real D2Q9 lattice. When a result looks
wrong, it's the physics that's wrong, which is most of why it's worth building this way.

Start anywhere in the gallery; each engine's page opens with a preview and a snippet that runs.
